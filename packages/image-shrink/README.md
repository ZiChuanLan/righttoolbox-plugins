# 图片压到指定大小

选中一张或多张图片 → **图片 → 压缩到指定大小**。典型用途：报名系统要求「照片不超过 200KB」、表单限制 2MB、微信发原图前瘦身。

## 策略

1. 先保持原尺寸，从 quality 92 一路降到 25 试编码，够小就收工——尽量保住清晰度。
2. 质量降到底还不够，才按 0.85 → 0.25 的比例逐档缩小尺寸，每档重新走一遍质量梯度。
3. 达标立即写盘，绝不二次压缩已有输出；原件永远不动，输出名形如 `photo_squeezed.jpg`。

透明 PNG 会先合成到白底（JPEG 不支持透明），避免出现黑底。输出统一为 JPEG。

## 参数

| 参数 | 说明 |
| --- | --- |
| 目标大小 | 100KB / 200KB / 500KB / 1MB / 2MB / 自定义 |
| 自定义上限 | 仅「自定义」时生效，10–20480 KB |
| 最长边限制 | 可选，先把超长边等比缩到上限再压 |
| 输出文件夹 | 留空则与原图同目录 |

结果表格会写明「原大小 → 新大小（质量、最终分辨率）」，方便判断是否压过头。
