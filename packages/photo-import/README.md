# 手机照片整理

选中手机导入的照片文件夹 → **图片 → 整理手机照片**。

## 一次解决导入后的三个麻烦

1. **HEIC 打不开** → 自动转 JPG（HEIC / HEIF / WebP / TIFF / BMP；PNG 保持原样，避免丢透明）。
2. **IMG_1234 完全看不懂** → 按 EXIF 拍摄时间重命名为 `20260101_143000.jpg`，没有 EXIF 时用文件修改时间。
3. **几千张堆在一个文件夹** → 自动分到 `2026/01/` 这样的年/月子目录。

还能顺手压到 ≤200KB / 500KB / 1MB / 2MB，适合直接发微信或上传。

## 安全设计

- `requiresPreview`：先列出「源文件 → 目标路径 + 动作」，确认后才动手。
- 移动而不是复制，避免照片翻倍；但原件路径在预览里写得很清楚。
- 目标已存在时自动加 `(1)` 序号，绝不覆盖已有照片。
- 转换失败（例如缺 HEIF 扩展）只影响那一张，结果表格标「失败」并写明原因，其余照片照常整理。
