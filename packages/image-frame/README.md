# 批量加边框 / 圆角

选中图片 → **图片 → 加边框 / 圆角**。

| 样式 | 效果 | 输出 |
| --- | --- | --- |
| 白边（打印留白） | 四边等宽白边，打印不裁到内容 | JPEG |
| 拍立得边框 | 白边 + 底部三倍留白（可写字） | JPEG |
| 细黑边 | 黑色细描边，方便浅色背景上看出边界 | JPEG |
| 圆角（透明） | 按短边百分比切圆角，四角透明 | PNG |

## 自适应宽度

边框宽度 = **图片长边 × 百分比**（默认 4%，范围 0–20）。所以 4000px 大图和 400px 小图看起来比例一致，不会出现「小图被白边吃掉」或「大图只有一条线」。

圆角半径 = **短边 × 百分比**（默认 8%，范围 2–50）。

输出 `原名_frame.jpg` 或 `原名_frame.png`，原件不动。
