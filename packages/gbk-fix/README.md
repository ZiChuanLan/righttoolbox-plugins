# 乱码文件名修复

典型症状：从旧 ZIP 解压出来的 `ÖÐÎÄËµÃ÷.rar`、`µçÄÔÑ§Ï°.pdf`，或 FTP 拖回来的中文名变成怪符号。

## 原理

GBK 编码的字节被当成 cp437 或 latin-1 显示。插件把文件名按 cp437 / latin-1 还原回原始字节，
再按 GBK / GB18030 / UTF-8 重新解码，得到正确的中文名。往返失败或解码结果含控制字符、路径分隔符的候选会被丢弃，
所以正常文件名不会被误改。

## 用法

1. 选中乱码文件或整个文件夹 → **文件 → 修复乱码文件名**。
2. 面板先给出「原名 → 新名」预览，与已有文件重名的项标记为「冲突，将跳过」。
3. 确认后才真正改名：只改名，不移动、不删除、不改内容。

## 实现要点

- 只使用 Python 标准库（`unicodedata`、`os`），运行时要求 Python 3.8+。
- 子项按「先深后浅」顺序改名，父目录先改名也不会让后续子项路径失效。
- 预览与执行之间文件若被占用或消失，逐项跳过并把原因写进结果表格。
