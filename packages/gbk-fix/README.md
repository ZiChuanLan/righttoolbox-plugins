# 乱码文件名修复

纯 C# 实现（`CodePagesEncodingProvider` 提供 cp437 / GBK），**不需要 Python**。

典型症状：从旧 ZIP 解压出来的 `ÖÐÎÄËµÃ÷.rar`、`µçÄÔÑ§Ï°.pdf`。

原理：GBK 编码的字节被当成 cp437 或 latin-1 显示。插件把文件名按 cp437 / latin-1 还原回原始字节，
再按 GBK / GB18030 / UTF-8 重新解码。往返失败或解码结果含控制字符、路径分隔符的候选会被丢弃，
所以正常文件名不会被误改。

## 用法

1. 选中乱码文件或整个文件夹 → **文件 → 修复乱码文件名**
2. 预览「原名 → 新名」，与已有文件重名的标为「冲突，将跳过」
3. 确认后才改名：只改名，不移动、不删除、不改内容

子项按「先深后浅」顺序改名，父目录先改名也不会让后续子项路径失效。
