# 批量文本替换

选中文件或文件夹 → **文本 → 批量文本替换**。纯 Python 标准库实现，要求 Python 3.8+。

## 行为

1. **预览**：只统计命中数，不动文件。含 `0x00` 字节的二进制文件自动跳过。
2. **写回**：重新读取并替换，保留原编码（UTF-8 / GBK / GB18030 自动探测）与原有 BOM。
3. **备份**：默认把原文件复制成 `同名.bak`；同名备份已存在时不再覆盖，避免冲掉第一份原始版本。

## 与「文本批处理工具」的区别

`community.text-ops` 负责**文件之间**的去重、排序、合并与统计；本插件负责**文件内容里**的查找替换，
两者互补。替换发生在每个文件内部，不做跨文件合并。
