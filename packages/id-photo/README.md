# 证件照裁切

选中照片 → **图片 → 裁成证件照**。

| 规格 | 像素 |
| --- | --- |
| 一寸 | 295×413 |
| 二寸 | 413×579 |
| 小一寸 | 260×378 |
| 大一寸 | 390×567 |

## 两种处理方式

- **居中裁切**（推荐）：按目标比例从图片中央取最大区域再缩放，不变形、不留边，适合本身就是人像的图。
- **完整留白**：整张图等比放进目标框，多余部分用背景色填充（白/蓝/红/浅灰），适合全身照或不想裁掉内容的场景。

输出 `原名_idphoto.jpg`（质量 95），原件不动。不会自动换背景（抠图需人工确认，避免把头发边缘搞坏）。
