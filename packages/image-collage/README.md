# 拼长图 / 九宫格

按资源管理器的选中顺序拼接（选中顺序即拼接顺序）→ **图片 → 拼接图片**。

| 拼接方式 | 适合 |
| --- | --- |
| 竖向长图 | 聊天记录、网页长截图、流程图 |
| 横向长图 | 对比图、时间线 |
| 九宫格 (3×3) | 朋友圈/小红书九宫格 |
| 四宫格 (2×2) | 商品细节、对比展示 |

## 规则

- **等比留白，不裁切**：图片按「完整可见」缩放到单元格内，多余空间用背景色填充，不会切掉内容。
- **背景色**：白 / 黑 / 浅灰 / 透明。选透明时输出 PNG，其余输出 JPEG（质量 92）。
- **尺寸保护**：成品最长边默认 4000px、总像素上限约 1 亿；超出时整体等比缩小，而不是报错。
- 输出文件名形如 `第一张图_collage.jpg`，永不覆盖已有文件。
