# JSON 批量格式化

选中一个或多个 `.json` / `.jsonc` / `.webmanifest` → **开发 → 格式化 JSON 文件**。

- **美化（2 / 4 空格）**：保留原有 CRLF/LF 风格与 UTF-8 BOM。
- **压缩为单行**：去掉全部空白，保留行尾换行。
- **按字母排序键后美化**：递归按 key 名排序，适合对比两个配置文件。
- **仅校验，不写回**：只报告哪些文件语法有问题，不动文件。

预览阶段列出每个文件「能否处理」，确认后才写回；默认生成 `.bak`，同名备份已存在时不再覆盖，避免冲掉第一份原始版本。

零第三方依赖，要求 Node.js 18+。
