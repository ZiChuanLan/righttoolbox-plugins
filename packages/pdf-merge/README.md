# PDF 合并 / 拆分 / 提取

选中 PDF → **文档 → PDF 合并 / 拆分 / 提取**。

| 处理方式 | 结果 |
| --- | --- |
| 合并为一个 PDF | 按选中顺序合并成 `第一个文件_merged.pdf`（至少选两个） |
| 每页拆成单独文件 | 每个 PDF 拆成 `原名_page01.pdf`、`原名_page02.pdf`… |
| 提取指定页码 | 按 `1-3,5` 这样的范围抽出 `原名_extract.pdf`，留空表示全部页 |

## 页码写法

- `3` 单页
- `1-5` 连续范围
- `1-3,7,9-10` 混合，自动去重并升序
- 超出范围的页码会被裁掉；全部越界则明确报错不会产出空文件

## 说明

依赖 [PDFsharp](https://github.com/empira/PDFsharp)（MIT）。合并走「导入页面再输出」，不会重新压缩原有内容，
所以文字仍是文字、图片仍是图片；不加密、不修改原有页面内容。

首次构建会从 nuget.org 还原 PDFsharp（仓库根已有 `NuGet.Config`）。
