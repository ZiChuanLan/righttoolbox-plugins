# 照片方向修正

选中照片 → **图片 → 修正照片方向**。

## 为什么会歪

手机拍照时把方向写进 EXIF（Orientation 0x0112），文件本身是横躺的。浏览器和手机相册会按 EXIF 转正，
但资源管理器缩略图、很多老软件不认，于是你就看到横着或倒着的图。

## 自动模式

按 EXIF 的 8 种取值做对应变换（不处理 / 左右镜像 / 180° / 上下镜像 / 顺时针 90° / 逆时针 90° 及两种转置组合）。

- 方向本来就正确的图（EXIF=1 或无 EXIF）**不会产生副本**，结果表格标「无需改动」。
- 每张图按自己的 EXIF 独立判断，批量处理不同朝向的照片不会串。

## 手动模式

顺时针 90° / 逆时针 90° / 180°，可叠加水平或垂直镜像——用于 EXIF 丢失或标错的文件。

## 输出

`原名_oriented.jpg`（PNG 输入仍输出 PNG 保留透明），质量 95，原件不动。
