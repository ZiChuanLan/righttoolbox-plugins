# 相似照片清理

选中相册文件夹 → **图片 → 查找相似照片**。

## 原理

每张图缩到 9×8 灰度并计算 **dHash**（64 位差异哈希）。两张图的汉明距离 ≤ 阈值就算相似——
所以它认得出「同一张照片被微信压过、被裁过、被改过尺寸」，而不只是字节完全相同的文件（那部分内置的「查找重复文件」已经做了）。

## 分组与保留规则

每组按 **像素总数 → 文件体积 → 文件名** 排序，保留第一张（最清晰的那张），其余视为重复。

## 两种处理方式

- **只分组检测**（默认）：只给分组结果，不动任何文件。
- **重复项移到 _duplicates**：每组重复项移到「保留图所在目录/_duplicates/」，同名自动加序号。是移动不是删除，随时能捡回来。

## 限制

- 单次上限 4000 张，超过请分批（避免一次扫整块盘卡住）。
- 无法解码的文件（损坏、缺 HEIF 扩展）静默跳过。
- 截图、纯色图彼此容易误判，处理前看一眼分组结果。
