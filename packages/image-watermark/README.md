# 批量加文字水印

选中图片 → **图片 → 批量加文字水印**。

## 位置

右下角 / 左下角 / 右上角 / 左上角 / 居中 / 平铺（-30° 斜向密铺，适合样图、报价单）。

## 细节

- **字号自适应**：按图片宽度封顶（宽度 ÷ 8），100px 宽的小图不会被打成全屏字。
- **不透明度**：5%–100%，默认 45%，既能看清又不遮内容。
- **白底合成**：透明 PNG 先铺白底再画水印，转 JPEG 不会出现黑块。
- **输出**：`原名_watermark.jpg`（质量 92），原件不动，同名自动加序号。

结果表格会列出每张图的位置、颜色、不透明度与输出体积。
