# 生成二维码

选中任意文件或文件夹（只用来决定保存位置）→ **图片 → 生成二维码**。

## 用途

- 网址变二维码，发群里让别人扫
- 一段长文字/收货地址，扫码即复制
- WiFi 免密输入：内容填 `WIFI:T:WPA;S:热点名;P:密码;;`
- 名片、群号、票号等固定文本

## 参数

| 参数 | 说明 |
| --- | --- |
| 内容 | 最多 1200 字符（再长二维码会密到扫不动） |
| 边长 | 96–4096 px，实际尺寸按模块数向上取整，保证每个模块是完整像素 |
| 纠错级别 | L 7% / M 15% / Q 25% / H 30%，越高越耐污损但同样内容更密 |
| 前景色 | 黑 / 深蓝 / 深绿 / 红（背景固定白，保证对比度） |
| 文件名 | 默认 `qrcode.png`，同名自动加序号 |

依赖 [QRCoder](https://github.com/codebude/QRCoder)（MIT），PNG 由它自己编码，不依赖 System.Drawing。
