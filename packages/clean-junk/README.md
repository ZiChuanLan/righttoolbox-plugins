# 清理垃圾文件与空文件夹

选中一个或多个文件夹 → **文件 → 清理垃圾文件与空文件夹**。

## 默认清理项

| 类别 | 匹配 | 默认 |
| --- | --- | --- |
| 缩略图/系统垃圾 | `Thumbs.db`、`ehthumbs.db`、`.DS_Store` | 开 |
| 临时文件 | `*.tmp`、`*.temp`、`~$*`（Office 锁文件残留） | 开 |
| 空文件夹 | 递归，先深后浅，删掉子项后变空的父文件夹不会连带删除 | 开 |
| 0 字节文件 | 仅当手动勾选 | 关 |

## 安全设计

- `requiresPreview`：先给完整清单（文件名、路径、体积）与合计大小，确认后才删除。
- 执行阶段重新校验：空文件夹必须仍然为空，文件必须仍然存在，否则跳过并记一行「已跳过」。
- 跳过符号链接与联接（`ReparsePoint`），不跟进别的卷。
- 递归深度上限 32，权限不足的目录静默跳过。
- 不删除任何可执行文件、库或用户文档——判定只看文件名后缀与空目录状态。
